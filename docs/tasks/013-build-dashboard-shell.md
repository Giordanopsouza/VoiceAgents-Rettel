# Build the engineering dashboard shell

## Scope
Create a responsive static interface served by FastAPI with clear regions for the voice call, dental schedule, Failure Lab, event timeline, and reliability result.

## Acceptance criteria
- [ ] The page establishes the fictional dental customer scenario immediately.
- [ ] The integration path and current demo state are understandable without reading the README.
- [ ] Empty, loading, ready, and error states have defined treatments.
- [ ] The layout works at common desktop and mobile widths.
- [ ] Keyboard focus, labels, contrast, and reduced-motion behavior support basic accessibility.

## Out of scope
- Live API data.
- Retell voice SDK integration.
- A separate marketing site.
